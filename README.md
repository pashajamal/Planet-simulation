# 🪐 2D Space Gravity & Planet Simulation

A real-time 2D orbital mechanics simulation built in Python using **Pygame**. It simulates gravity using Newton's Law of Universal Gravitation to plot realistic trajectories of the Sun and the 9 planets in our solar system.

## 🚀 Features
- **N-Body Gravity Simulation:** Calculates real-time gravitational pulls between all celestial bodies using the formula $F = G \frac{m_1 m_2}{r^2}$.
- **Orbital Trails:** Draws dynamic paths behind each planet to show their historic orbits.
- **Interactive Zooming:** Press the **`Z`** key to switch between a zoomed-out (full solar system) and zoomed-in (inner planets) view.
